Privacy Policy

Last updated: 19 November 2026

Kan Live Clips ("the app") is a personal tool run by one person (the "owner") on their own computer to post short clips of live gaming streams to the owner's own YouTube, TikTok and Instagram accounts.

What the app accesses

  • The owner's accounts. When the owner signs in with TikTok, Instagram or YouTube, the app receives an access token and basic account information (account ID, username, display name) so it can upload videos to that account. It requests only the permissions needed to read basic profile information and to upload and publish videos.
  • Public stream data. The app reads public live streams and public chat messages from Twitch and Kick to find exciting moments. Chat messages are processed in memory to measure chat activity and are not stored or shared.

How data is stored

Access tokens and clips are stored only on the owner's computer. Nothing is sold, rented or shared with third parties, and no analytics or advertising tracking is used. Videos and captions are sent only to the platforms the owner posts to (YouTube, TikTok, Instagram), and frames from clips may be sent to Google's Gemini API to write a title.

YouTube API Services

The app uses YouTube API Services to upload videos to the owner's YouTube channel. By using the app you agree to be bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

  • What it accesses: through Google sign-in (OAuth) the app asks only for the youtube.upload permission (to upload videos) and the youtube.readonly permission, used only to read the signed-in channel's ID and name (channels.list) to confirm which channel it uploads to. It does not read, collect or store any other YouTube user data, viewer data, comments or analytics.
  • How it is used: only to upload the owner's Shorts (video, title, description, tags) to the owner's own channel.
  • Sharing: YouTube API data is not shared with any third party.
  • Storage: the OAuth token and the channel ID are stored only on the owner's computer. No cookies or other tracking are placed on any device.
  • Revoking access: access can be revoked at any time on the Google security settings page.
  • Deletion: when access is revoked, or on request to the contact below, the stored token and channel ID are deleted within 7 days. Stored YouTube API data is never kept longer than 30 days without being refreshed.

Other people

The app has no public sign-up and does not collect personal data from visitors or other users. Streamers shown in clips are credited by name. A streamer who wants a clip removed can ask using the contact below and it will be taken down.

Deleting data

The owner can revoke the app's access at any time in their TikTok, Instagram (Meta) or Google account settings; the stored tokens are then deleted from the owner's computer.
